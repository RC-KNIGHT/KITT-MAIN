# Design System Guidelines

Strict adherence to the KITT Ecosystem aesthetic:
- **Obsidian Dark Void**: `#080f14` / `#0a1114`
- **Antique Gold**: `#A58D66` (buttons, popular tier tags, circuit traces, chip bodies)
- **Deep Oceanic Teal**: `#407E8C` / `#76B4C2` (atmospheric haze, via rings, secondary glow)
- **Warm Sand**: `#E5E1DD` (headings, body typography, star nodes)
- **Platinum / Pearlescent**: `#F5F2ED` / `#FFFFFF` (specular glints, terminal caps)

All modals must be portaled directly to `document.body` with accessible close (`X`) buttons at both top-right and bottom return buttons.
