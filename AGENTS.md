# KITT Ecosystem — Antigravity Agent Guidelines

This repository hosts **THE-KIT-ECOSYSTEM**, the AI-native electronics and engineering platform uniting:
1. **KITT 1.0 Autonomous Agent**
2. **Ravi Synthesis Workspace**
3. **DigiLogic Circuit Studio**
4. **Hardware Fabrication Labs**

## Core Tech Stack & Conventions
- **Framework**: React 19 + TypeScript + Vite
- **Styling**: Tailwind CSS v4 with custom surrealist palette:
  - **Antique Gold**: `#A58D66` (accents, popular badges, terminal caps)
  - **Deep Oceanic Teal**: `#407E8C` / `#76B4C2` (secondary glow, vias, atmospheric haze)
  - **Warm Sand**: `#E5E1DD` (primary typography, star nodes)
  - **Obsidian Dark Background**: `#080f14` / `#0a1114`
- **Particle & Canvas Physics**: High-performance 60–120 FPS 3D canvas systems (`SignatureHeroK.tsx`) using DPR clamping (1.5 max) and pre-allocated typed arrays.
- **Cross-Platform Database Hub**: `UserDashboardModal.tsx` provides multi-node synchronization across all 4 platforms.

## Commands
- Dev Server: `npm run dev` (running on `http://localhost:3000`)
- Build: `npm run build`
- Type Check: `npm run lint`
